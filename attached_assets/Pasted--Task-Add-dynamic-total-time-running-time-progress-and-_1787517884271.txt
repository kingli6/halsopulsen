# 4. Show total duration on the running timer

When the Massage sequence starts, I want to know not only the current section's remaining time but also how much time remains in the **entire sequence**.

For example:

```text
RIGHT ARM

2:14

Next
Left arm · 3:00


Total remaining
42:14

← Föregående      Hoppa över

             PAUSA

                 Avbryt
```

The exact visual layout can follow the existing design, but the information should be clearly available.

### Important distinction

There are two timers:

**Current section**

Example:

`2:14`

**Entire sequence**

Example:

`42:14 remaining`

The sequence timer must account for:

* Remaining time in the current section
* All subsequent sections
* Subsequent rounds/blocks if the existing timer supports rounds

It must NOT simply display the original total duration after the timer starts.

# 5. Make the total-time display clickable

Use a simple YouTube-like interaction.

The total-time display should be clickable/tappable.

For example, while running:

`42:14 remaining`

Tap it:

`3:46 elapsed`

Tap again:

`46:00 total`

Tap again:

`42:14 remaining`

Then repeat.

The exact wording can be:

* `46:00 total`
* `42:14 remaining`
* `3:46 elapsed`

or another concise format that fits the existing UI.

### Requirements

* The three states should cycle in a predictable order.
* It must be obvious that the total-time display is interactive.
* Do not make the interaction interfere with the current section timer.
* The current section timer should continue working normally.
* The display must update in real time.

### Calculation

At any point:

`total duration = sum of all sections`

`elapsed = total duration - total remaining`

`remaining = current section remaining + all later section durations`

Use the actual timer state rather than maintaining a second independent countdown that could drift.

## 7. Drag-and-drop UX

Use a familiar drag interaction.

Each section should have a clear drag handle, for example:

`⋮⋮`

Example:

```text
┌──────────────────────────────────┐
│ ⋮⋮  Right arm             3:00 × │
│     [-5s] [-1s] [+1s] [+5s]      │
└──────────────────────────────────┘
```

The drag handle should make it obvious that the section can be moved.

### Mobile is important

This timer will likely be used on a phone/tablet.

Make sure the implementation supports touch dragging.

Avoid making the entire card difficult to interact with because the card also contains:

* duration editing
* ±1s
* ±5s
* remove button

Ideally, dragging starts from the dedicated drag handle rather than any random touch on the card.

Do not accidentally start dragging when the user is trying to tap:

* the duration
* +/− controls
* the remove button


### Long sequence

Make sure the total works beyond 60 minutes.

For example:

### Reordering
